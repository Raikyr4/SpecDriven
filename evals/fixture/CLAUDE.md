# Loja (projeto de avaliação do padrão SDD)

Calcula preços de uma loja. Projeto mínimo usado só pelos evals do `SpecDriven`.

## Comandos
| Módulo | Build | Teste | Diretório |
| --- | --- | --- | --- |
| app | — | `python -m unittest discover -s app -p test_*.py` | `/app` |

## Fluxo
Toda mudança segue o padrão SDD (`/especificar` → `/planejar` → `/tarefas` → `/implementar` →
`/verificar`). Nunca marque `aprovado` e nunca commite.
